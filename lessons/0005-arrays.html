数组(Array)

循环最常见的搭档就是数组——批量存一堆同类型的数据,再用 for 遍历处理。 Java 数组是你遇到的第一个"引用类型的容器",也是后面学 List/ArrayList 集合类的铺垫。

1. 声明与初始化

int[] scores = new int[5];       // 声明一个长度 5 的 int 数组,默认全是 0
int[] ages = {20, 21, 19, 22};   // 声明并直接赋初值,长度由花括号里的个数决定
String[] names = {"Alice", "Bob"};
PythonTypeScriptJava
创建一个数组/列表 ages = [20, 21, 19](list,可变长,可混类型) let ages: number[] = [20, 21, 19]; int[] ages = {20, 21, 19};
长度能不能变 能(append/pop) 能(push/pop) 不能,Java 数组长度创建后固定,想要可变长度得用后面要学的 ArrayList
数组长度固定: new int[5] 创建后,这个数组永远是 5 个格子,没有"追加一个元素"这种操作。 这是 Java 数组和 Python list / JS array 最大的区别——它们的"数组"其实是动态数组,Java 原生数组不是。

2. 访问与遍历

int[] scores = {88, 92, 76};
System.out.println(scores[0]);   // 88,下标从 0 开始,和 Python/TS 一样
System.out.println(scores.length); // 3,注意是属性 length,不是方法 length()

for (int i = 0; i < scores.length; i++) {
    System.out.println(scores[i]);
}
length 不加括号: 数组用 .length(属性),但 String 用 .length()(方法)—— 这是 Java 的历史遗留不一致,记住"数组是 length,字符串是 length()"就行,IDE 也会在你打错时报错提醒。

3. 增强 for 循环(for-each)

int[] scores = {88, 92, 76};
for (int s : scores) {
    System.out.println(s);
}

只需要遍历元素、不需要下标时用这种写法,可读性更好。等价于 Python 的 for s in scores: 或 TS 的 for (const s of scores)。 需要下标(比如要同时访问 scores[i] 和 i)时才用普通 for。

预测一下:这段代码输出什么?

int[] nums = {10, 20, 30};
int total = 0;
for (int n : nums) {
    total += n;
}
nums[0] = 999;
System.out.println(total);
先自己想,想好了再展开看答案

输出 60。total 是在 for-each 循环结束之后才被 nums[0] = 999 修改的, 循环内部已经把 10+20+30 累加完毕并存进 total,后面改数组不会影响已经算好的 total。
