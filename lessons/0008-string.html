String:方法、不可变性与比较

前面零散用过 String,但没系统讲过。String 在 Java 里是一个引用类型(和 Integer 一样是对象),但它有一条重要规则:String 对象创建后内容不可变。 所有"修改"操作实际上都是在返回一个新的 String,原来的对象纹丝不动。

1. 创建 String

String s1 = "hello";                     // 字面量,最常用
String s2 = new String("hello");         // 强制 new 一个新对象(几乎不这么写)
别用 new String("..."): 字面量 "hello" 会被 JVM 放进字符串常量池复用,省内存。 new String(...) 绕过了这个优化,无谓多创建一个对象。直接 String s = "hello"; 就好。

2. 常用方法

String name = "Alice";

name.length();                    // 5,注意 String 是 length() 方法,数组是 length 属性
name.charAt(0);                  // 'A',取指定下标的字符
name.substring(1, 4);             // "lic",从下标1到下标4之前(不含4)
name.toLowerCase();               // "alice"
name.toUpperCase();               // "ALICE"
name.trim();                      // 去掉首尾空白
name.isEmpty();                   // false,长度是否为0
name.contains("li");              // true
name.startsWith("Al");            // true
name.endsWith("ce");              // true

// 证明不可变性:
name.toLowerCase();
System.out.println(name);         // 还是 "Alice"!toLowerCase() 返回了新字符串,没改原对象

3. 字符串比较:== vs equals()

String a = "hello";
String b = "hello";
String c = new String("hello");

System.out.println(a == b);         // true,同一个常量池对象
System.out.println(a == c);         // false,不同对象!
System.out.println(a.equals(c));    // true,equals 比的是内容

// 用户输入/从数据库/网络读来的字符串,永远用 equals!
String input = scanner.nextLine();
System.out.println(input == "exit");    // ✗ 错!可能是不同引用
System.out.println("exit".equals(input)); // ✓ 这样写还能避免 null.equals(...) 炸掉
Java 里 == 对引用类型比的是内存地址,不是内容! 这和 Python 里 is vs == 的区别类似,也和 TS 里 === 对对象的比对规则类似。 但 Java 的 equals() 不是语法层面内置的,是 Object 类定义的方法——String 覆写了它来比内容。 后面学自定义类的时候还会再碰到 equals 这个主题。

预测一下:这段代码输出什么?

String s = "Java";
s.toUpperCase();
s = s + "!";
System.out.println(s);
先自己想,想好了再展开看答案

输出 Java!。分步拆解:

  1. s.toUpperCase() 返回了 "JAVA",但没有赋值给任何变量,结果被丢弃
  2. s = s + "!" 创建了新字符串 "Java!" 并赋值给了 s

toUpperCase() 那一行等于白写——这是新手最常见的 String 陷阱。
