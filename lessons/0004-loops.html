循环:for 与 while

条件分支解决了"选哪条路走"的问题,循环解决"同一件事重复做"的问题——批量处理学生名单、重试请求、累加统计,都离不开循环。 Java 的循环语法和 TS/JS 几乎一致,和 Python 差异更大一些(Python 没有传统 C 风格 for,靠 range()/for...in 代替)。

1. for 循环

for (int i = 0; i < 5; i++) {
    System.out.println(i);
}
PythonTypeScriptJava
数 0~4 for i in range(5): for (let i = 0; i < 5; i++) {} for (int i = 0; i < 5; i++) {}
for (初始化; 条件; 每轮结束后执行) 三段式:初始化只跑一次,条件每轮循环前检查(必须是 boolean,和 if 一样), 第三段在每轮循环体跑完之后执行。三段都可以留空(比如 for (;;) {} 就是死循环),但这一课先都写全。

2. while 循环

int count = 0;
while (count < 3) {
    System.out.println(count);
    count++;
}

whilePython/TS 的写法几乎一样(条件同样要括号 + boolean)。什么时候用 for、什么时候用 while: 明确知道要循环几次(或者有个计数器)用 for;循环次数取决于运行时才知道的条件(比如"读到 null 为止")用 while。

3. break 与 continue

关键字作用
break立刻结束整个循环
continue跳过本轮剩余代码,直接进入下一轮

这两个关键字和 Python/TS 的行为完全一致,不用特别适应。

预测一下:这段代码输出什么?

int sum = 0;
for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        continue;
    }
    sum += i;
}
System.out.println(sum);
先自己想,想好了再展开看答案

输出 12。i 从 1 到 5,当 i == 3 时 continue 跳过 sum += i, 所以实际累加的是 1+2+4+5 = 12(3 被跳过了,不是循环提前结束)。
