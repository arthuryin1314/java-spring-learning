比较运算符、逻辑运算符与 if/else 条件分支

上一课搞清楚了基本类型和它们之间的自动转换规则。这一课往前走一步:怎么用这些值做判断,并根据判断结果走不同的代码分支—— 这是任何后端逻辑(权限校验、成绩等级、库存判断)都离不开的基础。

1. 比较运算符

运算符含义示例
==相等(基本类型比较值本身)age == 20
!=不相等age != 20
> < >= <=大小比较gpa >= 3.5
注意: == 对基本类型(int/double/boolean/char)比较的是值本身, 和 Python/TS 的 == 在数字上表现一致。但 == 用在 String 这种引用类型上时,比较的其实是"是不是同一个对象", 不是内容是否相同——这一点后面讲引用类型时会专门展开,这一课先只在基本类型上用 ==。

2. 逻辑运算符

运算符含义PythonTypeScript
&&与(两边都为 true)and&&
||或(至少一边为 true)or||
!非(取反)not!

3. if / else

int gpa = 85;
if (gpa >= 90) {
    System.out.println("A");
} else if (gpa >= 80) {
    System.out.println("B");
} else {
    System.out.println("C");
}

语法上和 TypeScript/JavaScript 的 if/else if/else 几乎一模一样;和 Python 比,区别是条件必须用小括号包起来, 分支体必须用花括号(单行也可以省略花括号,但不建议),而且没有缩进决定作用域这回事——Java 靠花括号,不靠缩进。

条件表达式必须是 boolean: Java 的 if 括号里只能放一个结果为 boolean 的表达式, 不像 Python/JS 那样"任何值都能当真假判断"(比如 if (0)``if ("")` 在 Python/JS 里合法,在 Java 里 if (0) 直接编译不过, 必须写成 if (0 != 0) 这种明确返回 boolean 的表达式)。

预测一下:这段代码输出什么?

int age = 17;
boolean hasParentConsent = false;
if (age >= 18 || hasParentConsent) {
    System.out.println("允许注册");
} else {
    System.out.println("拒绝注册");
}
先自己想,想好了再展开看答案

输出 拒绝注册。age >= 18false,hasParentConsent 也是 false, false || false 结果是 false,走 else 分支。
