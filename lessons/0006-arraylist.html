集合类型:ArrayList

上一课的痛点是数组长度固定,想要动态增删就得用 ArrayList——它是 Java 集合框架(Collections)里最常用的可变长度列表, 背后本质是一个会自动扩容的数组包装类。用法和 Python 的 list、TS 的 Array 概念一致,但 Java 的写法更啰嗦一些。

1. 声明与基本操作

import java.util.ArrayList;
import java.util.List;

List<String> names = new ArrayList<>();
names.add("Alice");
names.add("Bob");
names.add(0, "Zoe");        // 在下标 0 插入
System.out.println(names.get(1));   // "Alice"
System.out.println(names.size());   // 3,注意是 size(),不是 length
names.remove("Bob");                // 按值删除
names.remove(0);                    // 按下标删除
System.out.println(names.contains("Alice"));  // true
List<String> 和 ArrayList<String>: List 是接口,ArrayList 是它的一个实现类。 按惯例声明变量时用接口类型(List<String> names = new ArrayList<>()),这样以后想换成 LinkedList 之类别的实现,调用方代码不用改。 <String> 这种写法叫泛型,规定这个列表只能装 String,后面会专门讲,这里先照抄语法。

2. 数组 vs ArrayList,什么时候用哪个

int[] / String[]ArrayList
长度创建后固定可动态增删
基本类型能直接装 int/double 等只能装对象类型(Integer、Double,不能直接是 int)
常见场景长度提前确定、追求性能的场景绝大多数业务代码——元素数量运行时才知道
基本类型不能直接进 ArrayList: List<int> 是非法语法,必须写 List<Integer>。 Java 会在 add(5) 时自动把 int 包装成 Integer(叫"自动装箱" autoboxing),取出来时也会自动拆箱。 这一课先知道这个限制存在,原理后面讲包装类时再展开。

3. 遍历

List<String> names = new ArrayList<>();
names.add("Alice");
names.add("Bob");

for (int i = 0; i < names.size(); i++) {
    System.out.println(names.get(i));
}

for (String name : names) {   // for-each,和数组一样能用
    System.out.println(name);
}

预测一下:这段代码输出什么?

List<Integer> nums = new ArrayList<>();
nums.add(10);
nums.add(20);
nums.add(30);
nums.remove(1);
nums.add(99);
System.out.println(nums);
先自己想,想好了再展开看答案

输出 [10, 30, 99]。remove(1) 这里的 1 是下标(因为 nums 是 List<Integer>, remove(int index) 和 remove(Object o) 是两个重载方法,传 int 走的是按下标删除那个版本),删掉的是下标 1 的 20, 剩下 [10, 30],再 add(99) 追加到末尾变成 [10, 30, 99]。
