# 起点:零 Java 基础,但迁移能力强

用户明确表示对 Java **完全没有接触过**(一开始误以为可以类比着答诊断题,后主动纠正)。但具备扎实的 Python、TypeScript(在学中)、Vue 经验,并且有真实前后端项目经验(后端由 AI 代写)。

## Implications

- 不能假设任何 Java 特有语法或标准库知识(`==` vs `equals`、`Integer` vs `int`、泛型擦除等一律从零讲起)。
- **可以快速跳过**通用编程/类型系统概念:变量、函数、条件、循环、类/对象、接口、静态类型的意义——这些从 TypeScript 经验可以直接迁移,不需要重新解释"什么是类型"。
- 第一课应聚焦 Java **区别于 Python/TS 的结构性设定**:文件必须对应 public class、显式的 `main` 方法签名、`javac`/`java` 两步编译运行模型——这是 Python(直接解释执行)和 TS(编译到 JS,无强制入口签名)都没有的东西,是零基础学习者最先卡住的地方。
- 后续讲变量类型、集合、OOP 细节时,应持续做 Java ↔ TypeScript ↔ Python 的对比,这是用户明确要求的教学方式。
